现行缩略图（480px WebP q80）= 8948 B  ← 基线

[1] HTTP 传输层压缩（中间件对图片不做，因此这里只是证明「做了也没用」）
    + gzip -9      = 8877 B  (-0.8%)
    + brotli q11   = 8842 B  (-1.2%)
[2] 对已生成的 WebP 再做「无损 WebP 重编码」= 36556 B  (+308.5%)

[4] 参照（有损、像素会变，不做）：q70 = 7874 B (-12.0%)，q60 = 7592 B (-15.2%)
