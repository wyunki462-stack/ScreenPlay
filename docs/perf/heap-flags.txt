# Node 堆参数实测（宿主 node v24 + node:sqlite shim，同一套热接口，各 1200 次请求）
#
#   N=1200 STEP=400 NODE_OPTIONS=… bash scripts/perf-bench/bench-soak.sh
#
# 结论：四个变体的 RSS/耗时都在噪声范围内（互差 ≤ 2 MiB / ≤ 0.3 ms·次），
#       只有 --max-semi-space-size=8 明显更差（RSS +51 MiB、单次最慢 52 ms）；
#       --max-old-space-size 完全不改变 RSS（V8 堆常驻 ~40 MiB，离任何上限都很远）；
#       句柄数全程 1、SQL 形状数 29，都没有泄漏迹象。⇒ 不加堆参数（见报告 §二 方向 ① 与 §七）。
